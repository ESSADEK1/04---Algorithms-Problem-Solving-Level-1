Algorithms & Problem-Solving – Level 1

A collection of 50 C++ problem-solving solutions focused on writing clean, structured, reusable, and maintainable code.

This repository documents my progress through Algorithms & Problem-Solving – Level 1 (Clean Code Solutions), with an emphasis on transforming basic problem solutions into well-structured programs using functions and modular design.

🎯 Objectives

The main goal of this course is to develop the ability to:

Analyze programming problems systematically
Break complex problems into smaller sub-problems
Apply the Divide & Conquer approach
Design small and focused functions
Reduce code duplication
Improve code readability and organization
Build reusable and maintainable solutions
Develop better programming and software-engineering habits
🧠 Key Concepts

Throughout the projects, I practice:

C++ fundamentals

Functions and procedures

Divide & Conquer
Code reuse
Separation of responsibilities
Clean and readable code
Structured problem solving
